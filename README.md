## Source code

Download [cos106-student-portfolio-source.zip](cos106-student-portfolio-source.zip) for the complete Replit artifact source and public assets. The app is in the artifacts/student-portfolio directory inside the archive. Generated build output and installed dependencies are excluded.

The contact form validates input in the browser and does not transmit messages to a server. The study planner stores tasks in the browser's local storage.
